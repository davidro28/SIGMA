Use Case - Generar Reporte del Activo link

Properties
Name Value
Description

Este caso de uso permite que un usuario autorizado genere un reporte sobre un activo o grupo de activos. El sistema valida permisos, solicita los criterios de búsqueda, procesa la información en la base de datos y genera un reporte en el formato solicitado (PDF, Excel, etc.)..

Use Case Note
■ Workflow
    • El usuario selecciona los activos y criterios de generación, y el sistema construye el reporte solicitado.
■ Business Logic
    • Solo usuarios con permisos pueden generar reportes de activos.
    • Los reportes deben contener información precisa y actualizada.
■ Decisions
    • El sistema permite exportar el reporte en distintos formatos (PDF, Excel, CSV).
    • Se puede generar un reporte individual o consolidado de múltiples activos.
■ Follow-up
    • El sistema guarda un registro de los reportes generados.
    • Puede enviarse automáticamente por correo electrónico a los responsables.

Scenario
Steps
1. Administrador
2. Tecnico de Mantenimiento
3. El actor accede al sistema y selecciona la opción Generar Reporte de Activo.
4. El sistema valida permisos
5. El sistema realiza una descarga del formato.
6. El sistema adicional muestra un campo para poder subir nuevamente el formato
7. El sistema muestra crietrios de búsqueda (ID de activo, categoría, estado).
8. El sistema consulta la base de datos de activos.
9. El sistema procesa la información y genera el reporte.
10. El sistema guarda el reporte en la base de datos
11. El caso de uso finaliza mostrando un mensaje de confirmación.

Scenario2
Steps
1. 4(a). El usuario no tiene permisos → el sistema rechaza la acción
2. 10(a). Error en la base de datos → el sistema informa error y no genera el reporte.
