Iniciar sesion
■ Workflow
    • El usuario abre la aplicación e ingresa a la pantalla de inicio de sesión.
    • Escribe su nombre de usuario y contraseña.
    • Presiona el botón Iniciar Sesión.
    • El sistema valida las credenciales en la base de datos.
    • Si son correctas, redirige al usuario a la pantalla principal.
■ Business Logic
    • El sistema debe verificar que el usuario esté registrado y activo.
    • El sistema debe encriptar la contraseña antes de enviarla a la base de datos.
    • Si las credenciales no son válidas, debe mostrar un mensaje de error.
    • Debe permitir máximo 3 intentos fallidos antes de bloquear temporalmente la cuenta
■ Decisions
    • Se decidió incluir la opción “¿Olvidó su contraseña?” en la misma pantalla.
    • Se implementará reCAPTCHA después de 3 intentos fallidos para prevenir ataques.
    • El sistema debe redirigir automáticamente a la pantalla principal si el usuario ya tiene una sesión iniciada.
■ Follow-up
    • Validar con el cliente si se requiere autenticación en dos pasos (2FA).
    • Definir el tiempo de bloqueo de la cuenta después de los intentos fallidos.
    • Confirmar diseño visual del mensaje de error.
