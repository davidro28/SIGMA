Use Case - Consultar Disponibilidad del Activo link

Properties
Name Value
Description

permite a los usuarios consultar el estado actual de un activo dentro del sistema, verificando si está disponible, en uso, en mantenimiento o reservado. El sistema validará que el usuario esté autenticado y autorizado para acceder a la información. Al realizar la consulta, se recupera el estado actualizado desde la base de datos y se muestra al usuario en una vista clara.

Use Case Note
■ Workflow
    • El usuario accede al sistema, selecciona un activo y visualiza su estado en tiempo real.
■ Business Logic
    • El sistema debe consultar el estado directamente en la base de datos para evitar información desactualizada.
■ Decisions
    • Solo usuarios autenticados pueden consultar disponibilidad; se permite búsqueda por ID, nombre o categoría de activo.
■ Follow-up
    • Posible integración con notificaciones para alertar sobre disponibilidad futura o liberación de activos.

Scenario
Steps
1. Gestor de Tickets
2. Responsable
3. Administrador
4. El usuario accede al sistema y selecciona la opción Consultar disponibilidad de activo.
5. El sistema solicita los criterios de búsqueda (ID, nombre, categoría).
6. El usuario ingresa los datos del activo.
7. El sistema valida los permisos del usuario.
8. El sistema consulta el estado actual del activo en la base de datos.
9. El sistema muestra el estado (Disponible, En uso, En mantenimiento, Reservado).
10. El sistema registra la consulta en el módulo de auditoría.
11. El caso de uso finaliza.

Scenario2
Steps
1. 6(a). El usuario ingresa datos incompletos → el sistema solicita corrección.
2. 8(a). El activo no existe → el sistema informa al usuario que no se encontró el activo.
3. 8(b). Error en la conexión con la base de datos → el sistema muestra un mensaje de error y sugiere reintentar.
