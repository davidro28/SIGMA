Properties

Description

El administrador, tecnico, Gestor de Tickets o el responsable ingresa los datos del nuevo usuario (nombre, correo, credenciales iniciales, etc.), confirma el registro.
El sistema almacena la información, crea la cuenta y notifica la creación exitosa.

Use Case Note
■ Workflow
    • El usuario accede al módulo de Registro, introduce los datos del nuevo usuario y confirma el registro.
■ Business Logic
    • El sistema debe validar que los campos requeridos estén completos y que el correo no exista previamente. Luego crea el usuario y asigna un rol inicial.
■ Decisions
    • Solo los usuarios designados tienen permiso para registrar usuarios.
■ Follow-up
    • Verificar periódicamente que los datos registrados se mantengan actualizados y que los nuevos usuarios reciban las credenciales de acceso.

Scenario
Steps
1. Selecciona la opción Registrar.
2. Ingresa los datos requeridos (nombre, correo electrónico, credenciales iniciales, rol, etc.).
3. Verifica que la información esté completa y correcta.
4. Hace clic en Guardar/Confirmar.
5. El sistema valida los datos, crea la cuenta y muestra un mensaje de confirmación.

Scenario2
Steps
1. Si los datos están incompletos o el correo ya existe, el sistema muestra un mensaje de error y solicita corregir la información.
