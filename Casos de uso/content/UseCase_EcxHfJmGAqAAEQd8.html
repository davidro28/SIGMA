Description

El administrador registra un nuevo activo ingresando su nombre, número de serie (serial), y subiendo una imagen. El sistema almacena los datos y permite futuras consultas o ediciones del activo registrado.

Use Case Note
■ Workflow
    • El administrador accede al formulario de registro de activos.
    • Ingresa los datos del activo: nombre, serial, descripción, estado.
    • Adjunta una imagen del activo desde su equipo.
    • Hace clic en el botón "Registrar" para guardar la información.
    • El sistema valida los datos y guarda el activo en la base de datos
■ Business Logic
    • El sistema debe validar que el número de serie no esté duplicado.
    • La imagen debe cumplir requisitos de tamaño y tipo (.jpg, .png, etc.).
    • Si la validación es exitosa, se almacena en la base de datos y se genera un registro de auditoría (log).
    • El sistema notifica al usuario que el activo fue registrado exitosamente.
■ Decisions
    • El número de serie es obligatorio y único.
    • La imagen del activo es opcional, pero recomendable.
    • El campo "estado del activo" puede tomar valores como: Nuevo, Usado, Dañado.
    • Se decidirá más adelante si se integra con otro sistema de inventario.
■ Follow-up
    • Evaluar la posibilidad de editar o eliminar activos registrados.
    • Incluir campo de ubicación física del activo.
    • Implementar historial de cambios para trazabilidad.
    • Considerar la funcionalidad de asignar activos a usuarios.

Scenario
Steps
1. Administrador
2. El administrador inicia sesión en el sistema.
3. El administrador accede a la sección "Registrar Activo".
4. El sistema muestra el formulario para registrar un nuevo activo.
5. El administrador ingresa el nombre del activo.
6. El administrador ingresa el número de serie único del activo.
7. El administrador escribe una descripción detallada del activo.
8. El administrador selecciona el estado del activo (Nuevo, Usado, Dañado).
9. El administrador sube una imagen del activo (opcional).
10. El administrador presiona el botón "Registrar".
11. El sistema valida los datos ingresados:
12. Verifica que el número de serie no esté duplicado.
13. Verifica que la imagen cumple con los formatos permitidos.
14. Si la validación es exitosa, el sistema guarda el activo en la base de datos.
15. El sistema genera un log de registro para auditoría.
16. El sistema muestra un mensaje de confirmación al administrador.
17. El administrador puede optar por registrar otro activo o salir.
