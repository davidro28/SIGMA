Use Case - Restablecer Contraseña link

Properties
Name Value
Description

Este caso de uso permite a los usuarios restablecer su contraseña en caso de olvido. El proceso puede ser iniciado por el propio usuario a través de la opción "¿Olvidó su contraseña?" o por el administrador desde el panel de gestión. El sistema enviará un enlace de restablecimiento al correo electrónico registrado, el cual redirigirá al usuario a una pantalla para definir una nueva contraseña segura.

Use Case Note
■ Workflow
    • El usuario selecciona la opción "¿Olvidaste tu contraseña?" en la pantalla de inicio de sesión.
    • El sistema solicita al usuario ingresar su dirección de correo electrónico asociada a la cuenta.
    • El usuario ingresa el correo y presiona el botón "Enviar".
    • El sistema valida que el correo exista en la base de datos.
    • El sistema genera un token seguro y lo asocia temporalmente al usuario.
    • El sistema envía un correo con un enlace de restablecimiento de contraseña al usuario.
    • El usuario abre el correo y hace clic en el enlace recibido.
    • El sistema redirige al usuario a una página para ingresar una nueva contraseña.
    • El usuario ingresa la nueva contraseña y la confirma.
    • El sistema actualiza la contraseña en la base de datos y muestra un mensaje de confirmación.
■ Business Logic
    • El enlace de restablecimiento debe tener una validez limitada (por ejemplo, 15 minutos).
    • Si el token es inválido o ha expirado, el sistema debe rechazar la solicitud y notificar al usuario.
    • La nueva contraseña debe cumplir con los criterios de seguridad definidos (longitud mínima, combinación de caracteres, etc.).
    • El sistema debe invalidar cualquier token anterior una vez se use uno nuevo.
■ Decisions
    • Se acordó implementar validación de complejidad de contraseña: mínimo 8 caracteres, al menos una mayúscula, una minúscula, un número y un carácter especial.
    • Se decidió utilizar un proveedor de correo transaccional para mejorar la entregabilidad del email de restablecimiento.
    • La pantalla de restablecimiento tendrá validación en tiempo real (JavaScript) para mejorar la experiencia de usuario.
■ Follow-up
    • Definir el diseño de las pantallas de restablecimiento de contraseña
    • Configurar correctamente el servidor SMTP para envío de correos.
    • Realizar pruebas con expiración de token y errores comunes.
    • Revisar logs de eventos para verificar trazabilidad del proceso.

Scenario
Steps
1. El usuario accede a la opción "¿Olvidaste tu contraseña?" en la pantalla de inicio de sesión.
2. El sistema muestra un formulario solicitando el correo electrónico asociado a la cuenta.
3. El usuario ingresa su correo y presiona el botón "Enviar".
4. El sistema valida que el correo exista en la base de datos.
5. El sistema genera un token único de seguridad con tiempo de expiración.
6. El sistema envía un correo al usuario con un enlace de restablecimiento.
7. El usuario abre el correo y hace clic en el enlace.
8. El sistema valida que el token sea válido y no haya expirado.
9. El sistema muestra un formulario para ingresar y confirmar la nueva contraseña.
10. El usuario ingresa la nueva contraseña y la confirma.
11. El sistema valida que la contraseña cumpla con las políticas de seguridad.
12. El sistema actualiza la contraseña en la base de datos.
13. El sistema muestra un mensaje de confirmación al usuario.
14. El usuario puede iniciar sesión con su nueva contraseña.
