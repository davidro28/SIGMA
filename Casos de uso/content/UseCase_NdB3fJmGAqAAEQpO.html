Use Case - Asignar Teccnico link

Properties
Name Value
Description

permite que un administrador o gestor de tickets seleccione un técnico disponible y lo asigne a una solicitud de mantenimiento. El sistema valida la existencia del técnico, su disponibilidad y habilidades requeridas, registra la asignación y notifica tanto al técnico como al solicitante.

Use Case Note
■ Workflow
    • El administrador o gestor de tickets selecciona una solicitud pendiente y asigna a un técnico para su resolución.
■ Business Logic
    • Solo técnicos con disponibilidad pueden ser asignados.
    • El sistema debe validar que el técnico tenga las competencias requeridas para el tipo de mantenimiento.
■ Decisions
    • En caso de múltiples técnicos disponibles, el administrador decide a cuál asignar.
    • El sistema puede sugerir técnicos según carga de trabajo.
■ Follow-up
    • El técnico recibe notificación de la asignación.
    • El solicitante es informado del nombre del técnico asignado.

Scenario
Steps
1. Gestor de Tickets
2. Administrador
3. El administrador o gestor de tickets accede al sistema y selecciona la opción Asignar Técnico.
4. El sistema muestra la lista de solicitudes pendientes.
5. El administrador selecciona una solicitud específica.
6. El sistema muestra la lista de técnicos disponibles y sus perfiles.
7. El administrador selecciona un técnico.
8. El sistema valida disponibilidad y competencias del técnico.
9. El sistema registra la asignación en la base de datos.
10. El sistema notifica al técnico asignado y al solicitante.
11. El sistema registra la acción en el módulo de auditoría.
12. El caso de uso finaliza mostrando un mensaje de confirmación.

Scenario2
Steps
1. 5(a). No existen solicitudes pendientes → el sistema muestra mensaje informativo.
2. 6(a). No hay técnicos disponibles → el sistema sugiere reintentar más tarde.
3. 8(a). El técnico no cumple los requisitos → el sistema impide la asignación y sugiere otro técnico.
4. 9(a). Error en la base de datos → el sistema informa error y no registra la asignación.
