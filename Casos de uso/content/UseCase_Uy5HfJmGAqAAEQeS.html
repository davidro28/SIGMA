Scenario
Steps
1. El sistema muestra el formulario para cargar la foto del activo.
2. Administrador
3. El administrador selecciona la imagen desde su dispositivo.
4. El administrador sube la imagen.
5. El sistema valida que la imagen cumpla con el formato y tamaño permitido.
6. El sistema almacena la imagen en el repositorio correspondiente (base de datos o sistema de archivos).
7. El sistema asocia la imagen al registro del activo correspondiente.
8. El sistema confirma que la foto se ha subido correctamente.
9. El usuario recibe una notificación de éxito.
10. El sistema retorna al caso de uso principal (Registrar Activo) o al menú principal según corresponda.

Preconditions El usuario debe estar autenticado y autorizado para solicitar fotos de activos. Solicitar Foto del Activo
Post-conditions La foto del activo ha sido correctamente almacenada y asociada al activo correspondiente. El usuario recibe confirmación de la operación exitosa.
Author
Assumptions El sistema tiene capacidad para almacenar imágenes. El usuario cuenta con un dispositivo que permite subir imágenes (cámara o archivos). El tamaño y formato de las imágenes cumplen con las políticas establecidas por el sistema.
