Gestion de Tickets : System

Use Case - Eliminar Ticket link

Properties
Name Value
Description

describe cómo un actor autorizado elimina un ticket existente en el sistema.
El sistema valida permisos y estado del ticket antes de proceder.
Una vez eliminado, el sistema guarda un registro en el historial de auditoría y envía notificaciones a los usuarios relacionados.
La eliminación es lógica (el ticket se marca como inactivo) para preservar trazabilidad.

Use Case Note
■ Workflow
    • El usuario autorizado accede al módulo de gestión de tickets.
    • Selecciona el ticket que desea eliminar.
    • El sistema muestra un mensaje de confirmación de eliminación.
    • El usuario confirma la eliminación.
    • El sistema elimina el ticket y registra el evento en el historial.
■ Business Logic
    • El sistema debe validar permisos antes de permitir eliminar.
    • El sistema debe mantener trazabilidad del ticket eliminado en logs de auditoría.
    • La eliminación debe ser lógica, no física.
■ Decisions
    • Solo los roles Administrador y Gestor de Tickets pueden eliminar tickets.
    • Los usuarios responsables o solicitantes no podrán eliminarlos.
    • Se decidió enviar notificación automática al responsable del ticket eliminado.
■ Follow-up
    • Validar con el área de soporte si se permite restaurar un ticket eliminado.
    • Confirmar si la eliminación debe impactar en reportes históricos.
    • Revisar políticas de retención de datos para tickets eliminados.

3. Accede al módulo de gestión de tickets.

5. El sistema muestra un mensaje de confirmación.

Preconditions El usuario debe estar autenticado en el sistema. El ticket debe existir en el sistema. El usuario debe contar con permisos de eliminación (Administrador o Gestor de Tickets). Eliminar Ticket
Post-conditions El ticket se elimina del sistema. Se genera un registro en el historial de auditoría indicando qué ticket se eliminó, quién lo eliminó y cuándo. Los actores relacionados reciben una notificación de eliminación.
Author
Assumptions Se asume que el sistema no permitirá eliminar tickets que estén en estado Cerrado salvo que el rol sea Administrador. Se asume que la eliminación es lógica (se marca como inactivo en base de datos) y no física, para mantener trazabilidad. Se asume que el sistema está disponible y funcionando correctamente.
